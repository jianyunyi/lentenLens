# 首个可运行版本验收记录（历史）

最后更新：2026-10-08。范围为 v0.3 的首个 M0/M1 实现切片，不代表当前版本或完整 MVP 验收。下方记录仅描述当时运行结果。

## 当前发行与练习状态（0.7.1）

- 手动分发目标：Windows x64 VSIX；清单 publisher 为 `intentlens-local`，许可证为 MIT，与根目录 `LICENSE` 一致。该 publisher 不是 Marketplace 发布身份。
- 练习题生成、独立目录作答、题目/作答数据保存和应用差异预览已实现。
- 题目验证和作答评分依赖 Go 测试代码执行；由于 Windows、Linux、macOS 沙箱尚未实现并通过隔离验证，执行入口保持关闭。因此验证与基于测试的评分仍未交付。
- 以上状态描述代码和配置，不代表 0.7.1 VSIX 已在本机重新打包或通过当次发布验收。

## 回归覆盖

- 起始工作区基线、撤销改动、文件新增/删除、重复 Stop、会话不匹配、重叠轮次。
- 默认排除、递归规则、错误规则失败关闭、路径越界、Windows 目录联接。
- 单文件与总量上限；遗漏项不伪造新增/删除；规则中途放开时缺少基线明确保留未知。
- 私有状态必须在仓库外；排除规则变更后清除历史记录及依赖解释，恢复规则也不会恢复已清除内容。
- 直接调用、函数变量遮蔽、语法错误、竞争声明；不会任意选择平台条件文件作为唯一调用目标。
- 历史证据版本、轮次解释读取与过期、后台分析失败的可见诊断。
- 模型未启用或预算不足不发请求；伪造引用被省略；证据检查失败不标为支持。
- Windows PowerShell UTF-8 BOM 兼容；无需输入的命令不等待 stdin。
- VS Code 路径与链接越界拒绝、动态文本转义；排除变更关闭缓存面板，证据操作重新检查。

## 已发现并修复的主要问题

独立审查发现旧内容仅被隐藏、遗漏文件误报删除、平台重复声明被错误唯一定位，以及自动轮次解释缺少读取入口。对应修复已加入回归测试。

环境冒烟发现 PowerShell 管道 BOM 导致输入解析失败，现已兼容；另加测试防止兼容处理让无输入命令等待 stdin。VS Code 面板显示属于异步事件，集成测试按事件等待再断言。

## 尚未验证或交付

- 当前命令路径未找到 Claude Code：真实会话的开始、停止、中断和并发行为尚未实测。
- 未调用付费模型、未读取其他工具的凭据，真实账户、模型 ID、额度及解释质量待项目启用后验证。
- 共享生成与确认、逐条纠错、小修改题、执行确认与评分、答案应用尚未实现。
- 不捕获 prompt/transcript；不做跨包完整类型加载；大仓库性能及完整构建条件支持待完善。
- 费用金额未配置费率，界面只显示实际 token 与保守未决占用，不能称为货币预算控制。
- 尚无 3–5 位真实用户的持续使用结果，不能声称已验证产品价值。

本次没有发布扩展市场，没有提交或推送远程仓库，没有把扩展安装进日常 VS Code 配置，也没有修改现有项目的 Claude hooks。
