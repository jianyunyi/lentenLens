## 📦 Installation

下载 intentlens-0.6.1.vsix 并在 VS Code 中安装：
1. 打开 VS Code
2. 按 Ctrl+Shift+P
3. 输入 "Install from VSIX"
4. 选择下载的 VSIX 文件

## 🔄 Upgrade Notes

如果您正在使用 v0.6.0 且遇到锁错误，请：
1. 关闭所有 VS Code 实例
2. 删除项目中的 .intent 目录
3. 安装 v0.6.1
4. 重新打开项目
